  % CONCLUSIONS
  \section*{\sectiontitle{Conclusions}}
  \begin{itemize}
    \item Medium vocabularies ($|V| \in \{10,16\}$) and message lengths ($n \in \{2,4\}$) perform best
          % \item Interactive communication leads to better performance over non-interactive 
          % \item Interaction is a requirement for learning (see baseline)
    \item Scene complexity (number of distractors, number of features) dramatically impacts communication success
    \item Shape attributes easiest to learn, size attributes most challenging
    \item Future: Analyze linguistic properties of emergent languages
  \end{itemize}
